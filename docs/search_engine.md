# Search Engines

A search engine allows users to find relevant documents using keyword queries.

The main components of a search engine are:

- Crawler
- Parser
- Indexer
- Query Processor
- Ranker

An inverted index maps terms to the documents that contain them.

Popular ranking algorithms include TF-IDF, BM25, and PageRank.

Modern search engines often combine traditional information retrieval techniques with machine learning models.
